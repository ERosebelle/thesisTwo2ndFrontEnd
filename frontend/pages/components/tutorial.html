Password Analysis Result Tutorial

This guide introduces the sections of the Password Analysis Result page and explains how to use each available feature.

1. Result Summary

The Result Summary gives you a quick overview of the password analysis, including its vulnerability classification and overall security assessment.

VIDEO PLACEHOLDER 1920 × 1080 MP4 · 10–15 seconds

2. Decision Tree

The Decision Tree shows how the system reaches its classification. Open the detailed tree to inspect the decision path and select individual nodes for more information.

3. Recommendations

Recommendations identify improvements based on the detected weaknesses in the analyzed password.

4. Feature Vector

The Feature Vector displays the characteristics extracted from the password and used by the classification model.

5. Comparison

Comparison allows you to examine differences between password analyses and see how changes affect security and vulnerability.

7. Reset

Reset ends the current analysis session, clears the displayed results, and returns the system to the Initial Test page.

7. Compare Password

Compare Password starts another analysis while keeping the previous result available for comparison.

8. Tutorial

Tutorial reopens this guide so you can review the available features and explanations at any time.
